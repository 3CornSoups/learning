# Repository guidance

- Read `MAINTENANCE.md` before reorganizing learning materials.
- Keep topic folders directly under the repository root: `RAG/`, `MinimaxH3/`, and future topic folders. Avoid deep nesting.
- When adding a topic or a primary document, update the root `README.md` with a short, direct link.
- Keep notes, source references, and useful artifacts close to the topic they belong to.
- Preserve original source files and distinguish source content from summaries, interpretations, and hypotheses.
- Do not claim an experiment was reproduced unless it was actually run; record version, command, data, and outcome for runs.
- Avoid copying large model weights or generated caches into the repository. Link to their source and document retrieval steps instead.
- Use concise Markdown with descriptive headings, relative links, and readable tables. Prefer one clear topic index over many nested index files.
- Before moving or renaming material, check relative links and update affected topic/root READMEs.
