# Bilibili 抓取与下载工具

此目录包含本地 Bilibili 视频搜索、链接解析、批量下载、并发下载及统计脚本。

## 入口

- 使用说明.md：依赖、登录态配置、运行边界。
- 批量下载使用方法.md：URL 清单和批量任务。
- 五并发下载说明.md：并发下载配置。
- 抓取统计说明.md：统计脚本输入与输出。
- download_bilibili.py、search_random_bilibili.py：主要命令行入口。

Cookie 不包含在仓库中。运行前通过个人环境自行配置，并确认输出目录、平台条款和访问权限。该快照未在公开副本上重新运行；各说明中的历史测试结果仅代表其记录时的环境。
