# 运行与排障

| 现象 | 下一步 |
|---|---|
| 环境不存在 / doctor 返回 2 | 核对 `./server/.venv` 和 Python 3.12；使用独立环境执行 setup，不同步共用 `shared system environment` |
| Cookie 格式错误 | 重新复制完整请求头值；不是单个 Cookie 字段、JSON、HAR 或 Netscape 文件 |
| metadata.missing_uifid=true | 确认 Cookie 含 UIFID/UIFID_TEMP，并通过 run.py 而非直接运行 vendor 脚本 |
| metadata.argus_rejection=true | 可能接口兼容参数已失效；停止批量，先更新会话，维护者再独立排查兼容适配 |
| HTTP 200 但 has_detail=false | 不等于成功，可能是空数据或验证响应；单条确认并检查账号访问情况 |
| MP4 校验失败 | 保留文件与报告，用新输出目录检查；不要直接删除原文件后当作成功 |
| 重复运行 downloaded=0 | 查看 skipped，已完整存在的文件不会再次下载；测速需全新目录 |
| 图集失败 | 当前服务器视频入口不把图集当成 MP4；请从清单剔除或另建图集处理器 |
| 锁冲突 | 已有任务使用输出目录；换目录或等待任务退出，不要删除锁文件 |
| 分段失败 / 超过 100 MB | 默认单连接无此分段大小上限；独立新批次使用 `--segments 1` 比较；不自动拼接异常范围 |
| 没有 ffprobe | 使用 basic，或由维护者提供服务器已有 ffprobe；不在系统环境临时装 Python 依赖 |

报告不写 Cookie、签名媒体 URL 和后端原始异常，接口证据只保留状态、详情是否存在等结构化字段。分享报告前仍检查作品 ID、文件名、路径是否适合共享。

速度 `batch_MBps = 新增成功文件字节 / 1000000 / 整批耗时`，包括元数据、下载和校验；跳过旧文件不计入新增字节。单次报告不计算多轮波动率，比较稳定性需对同样输入在新目录重复运行，保留各轮 JSON。暂停、重试、等待会降低整批平均值。

恢复时保留报告中的 failed 项和 pending_ids。程序不提供定时调度、Cookie 自动续期、验证码求解或跨进程分页恢复。先将任务拆为可验收小批，再由团队调度系统管理。结束后检查本次 Python/ffprobe 及分段子任务已退出，不能误停其他人的服务。
