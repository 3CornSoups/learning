# 视频实体复用

服务器个人任务使用 `CZK_VIDEO_STORE=./data/videos`。新下载先完成容器、大小和散列检查，再在同一文件系统内原子移动到内容寻址目录，批次中建立软链接。已有实体在当前接口提供的 MD5 和大小匹配后复用；接口未提供散列时不凭作品 ID 跨批次认定媒体版本相同。

链接登记记录真实路径、大小、SHA256、设备和 inode；每次复用重新验证。未登记、失效、被替换或损坏的链接会失败，不会降级为成功或覆盖目标。临时下载文件拒绝指向软链接。

`run.sh` 提供个人目录默认值，Python 环境仍为 `./server/.venv`。本地 Windows 未设置资产目录时维持原有下载行为。发布包只包含白名单代码、文档和测试，不携带视频、模型、登录态及缓存，也不会展开软链接。

Codex 使用 `~/projects/Video_group/czk/bin/codex-czk`，配置和个人状态由 `CODEX_HOME` 限定在 `czk/.codex`。原版三视图实验由同级 `qwen-threeview` 组织；爬虫不依赖它的 GPU 环境。
