# RAG｜阅读入口

本专题关注知识变化时，RAG 如何表示、检索和维护证据。四项工作讨论的是不同问题，不构成可以直接互换或拼接的一套系统：ProStruct-RAG 处理命题关系与时间更新，AURORA 适应检索分布变化，GFM-RAG 检索图上的多跳证据，HyperRAG-IHM 增量维护超图结构。

## 建议阅读顺序

1. 先看[四项工作的总览与对照](四项RAG工作详读.md#1-总览四项工作分别改了-rag-的哪一层)，建立问题边界。
2. 按兴趣阅读下方对应原文；比较数字时回到论文的数据集、指标、基线和表格设置。
3. 用[HTML 导读](index.html)快速回顾方法流程，并准备讨论问题。

完整的研究问题、方法过程、证据、局限和讨论记录都维护在[详读 Markdown](四项RAG工作详读.md)；HTML 提供视觉导航和概览。

后续用 AI 更新本专题时，遵循[RAG 专题写作要求](../AI写作指引.md#rag-专题写作要求)，把新讨论先沉淀到详读 Markdown，再同步 HTML 中对应的结论和链接。
