# RAG 附属资料

这里收纳阅读主线之外、需要时再查的原始附件与研究资源，避免它们挤占 RAG 目录首页。

- `code/`：作者仓库源码 ZIP、解出的 KAPipe 文档、实验脚本与 Asteria 数据集。
- `sources/`：ACL Anthology / 项目网页快照、BibTeX 与 README。
- `extracted/`：论文文字提取，便于搜索；校对以 PDF 原文为准。
- `assets/`：论文页图片、原图及网页预览图。
- `manifest.json`、`manifest_extra.json`：下载来源、获取日期、SHA-256 与失败记录。
- `verification.json`：原 HTML 的交互与链接检查记录。

日常阅读通常只需打开上级目录中的论文 PDF、[详读 Markdown](../四项RAG工作详读.md) 或 [HTML 导读](../index.html)。
